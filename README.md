# 쿠폰지킴이 (Android MVP)

## 기능
- SMS 문자에서 쿠폰/유효기간을 감지해 기기에 저장
- 쿠폰 만료 전날 Android 캘린더 알림 생성
- Google Sheets를 공유 저장소로 사용해 가족 기기 간 쿠폰/사용 상태 동기화
- 쿠폰을 사용 완료 처리하면 공유 시트에 상태를 반영하고, 동기화한 기기에서 앱 알림과 등록된 캘린더 일정을 취소
- WorkManager가 최소 15분 주기로 동기화하며, 앱 실행/쿠폰 변경 시에도 동기화를 요청

## 공유 기능 설정

1. Google Sheets에서 새 스프레드시트를 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고 `google-apps-script/Code.gs` 내용을 붙여 넣습니다.
3. 코드의 `SHARED_KEY`를 가족끼리 공유할 임의의 긴 문자열로 바꿉니다. 예: 비밀번호 관리자로 생성한 긴 무작위 문자열.
4. Apps Script에서 **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 사용자는 본인, 액세스 권한은 **모든 사용자**로 설정하고 배포합니다.
5. 생성된 `https://script.google.com/macros/s/.../exec` 주소와 공유 키를 각 가족 휴대폰 앱의 **공유 시트 연결 설정**에 입력합니다.
6. 각 기기에서 **지금 동기화**를 누르고 알림/캘린더 권한을 허용합니다.

웹 앱 URL이나 공유 키를 모르는 사람에게 전달하지 마세요. 이 방식은 개인/가족용 간단한 공유를 위한 것으로, 강력한 사용자별 인증을 제공하지 않습니다.

## 동기화 동작과 제한
- 쿠폰 등록 기기는 쿠폰을 시트에 업로드하고, 다른 기기는 동기화 후 쿠폰 알림/만료 캘린더 일정을 생성합니다.
- 사용 완료 처리는 시트에 반영됩니다. 다른 기기는 다음 동기화에서 앱 알림 및 앱이 생성한 캘린더 일정을 취소합니다.
- 별도 서버 운영비는 없지만 **실시간 FCM PUSH는 아닙니다**. Android WorkManager는 배터리/OS 상태에 따라 15분보다 늦게 실행될 수 있습니다.
- 시트 동기화는 Apps Script의 무료 사용량 한도에 따릅니다.
- 현재는 SMS 본문 기반이며 MMS/이미지 OCR, 삼성월렛 연동, 복잡한 날짜 형식은 지원하지 않습니다.
- Google Play 배포 시 SMS 권한 정책 검토가 필요합니다.

## 빌드
Android Studio에서 프로젝트를 열고 Gradle sync 후 `assembleDebug` 실행. GitHub Actions workflow도 포함되어 있습니다.
