# 쿠폰지킴이 (Android MVP)

## 기능
- SMS 문자 본문에서 쿠폰/유효기간 키워드와 날짜를 감지
- 감지된 쿠폰을 앱 내부에 저장하고 알림 표시
- 캘린더 쓰기 권한과 사용 가능한 캘린더가 있으면 만료 전날 알림 일정을 생성
- GitHub Actions로 Debug APK 빌드

## 알려진 제한
- 현재는 일반 SMS 본문만 처리합니다. MMS/이미지/바코드 OCR은 구현되지 않았습니다.
- 날짜 파서는 규칙 기반 MVP이므로 모든 문자 형식을 정확히 인식하지 못합니다.
- 삼성월렛에 외부 앱이 쿠폰을 자동 추가하는 공식 연동은 확인되지 않아 직접 등록 기능은 포함하지 않았습니다.
- Android SMS 권한은 민감 권한입니다. 이 APK는 테스트/사이드로드용이며 Google Play 배포에는 정책 검토가 필요합니다.
- 알림/캘린더 권한을 허용해야 기능이 작동합니다.

## 빌드
Android Studio에서 프로젝트를 열고 Gradle sync 후 `assembleDebug` 실행. GitHub Actions workflow도 포함되어 있습니다.
